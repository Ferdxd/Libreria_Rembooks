# Libreria_Rembooks

Sistema de gestión y punto de venta para pequeñas librerías.

Características
• Punto de venta
• Control de inventario
• Registro de compras
• Gestión de proveedores
• Categorías de productos
• Control de precios y existencias
• Exportación de información

Tecnologías
• C#
• .NET 8
• WPF
• Entity Framework Core
• SQLite
• ClosedXML
